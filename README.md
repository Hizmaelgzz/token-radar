Token Radar (radar-2): a dashboard that ranks pre-token DeFi protocols by implied value, derived from a sealed DefiLlama snapshot. TVL is priced at the market's own median market-cap-to-TVL ratio from the snapshot's live-token protocols, then adjusted for seven-day growth, age with no token, and chain breadth — with a concrete seven-step farm plan, costs and times, for every protocol on the board.

## Run it

```sh
mkdir -p out
MAKEFUN_OUTPUT_DIR=out node main.ts --input /input/snapshot.json
```
